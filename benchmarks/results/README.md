# Benchmark result catalog

This directory contains the small, machine-readable records used by the
project documentation. Values are preserved exactly as emitted by the
benchmark runners. The runs used normalized deterministic FP32 data, and each
CSV records its workload, warm-up/measurement counts, hardware, CUDA Toolkit,
and compiler metadata.

Results from different benchmark runs are not interchangeable. Host-to-device
timing in particular varied between the baseline/warp and resident process
runs, so use within-file comparisons and retain each file's timing scope.

## Baseline decomposition

- `baseline_crossover.csv`: CPU versus `cuda-naive` across database sizes at
  `D=128`.
- `baseline_dimension.csv`: CPU versus `cuda-naive` at `D=128,256,768`.
- `stage_timing.csv`: allocation, copies, kernel, CPU Top-K, cleanup, and
  end-to-end timing for the naive CUDA pipeline.

Generated by `scripts/run_baseline_benchmarks.py`.

## Block-per-vector comparison

- `block_primary.csv`: the primary `N=100,000,D=768` run.
- `block_dimension.csv`: the controlled `D=128,256,768` sweep.
- `block_small_workload.csv`: the `N=10,000,D=128` overhead check.
- `block_comparison.csv`: the three groups above in one table. The primary and
  dimension-sweep `D=768` rows are independent runs and are intentionally
  retained separately.

Generated by `scripts/run_block_benchmarks.py`.

## Warp-per-vector comparison

- `warp_primary.csv`: the headline controlled `N=100,000,D=768` comparison.
- `warp_dimension.csv`: the `D=32..1024` sweep; the plots use only its
  `D=128,256,768` rows.
- `warp_small_workload.csv`: the `N=10,000,D=128` overhead check.
- `warp_comparison.csv`: the three groups above in one table.

Generated by `scripts/run_warp_benchmarks.py`.

## GPU-resident database

- `resident_cold_start.csv`: one-shot stateless latency versus resident preparation
  plus first-query latency.
- `resident_comparison.csv`: warm stateless/resident means, medians, and stage means
  over repeated query batches.
- `resident_amortization.csv`: preparation-inclusive totals for 1, 2, 5, 10, 20,
  and 100 query batches.

Generated by `scripts/run_resident_benchmarks.py`. The former warm and
dimension-specific copies were byte-for-byte duplicates of
`resident_comparison.csv`; they are not retained separately.

## Figures

Run:

```bash
python3 scripts/plot_benchmark_results.py
```

This reads `warp_dimension.csv` and writes the two PNG figures under
`docs/images/`. It does not rerun or modify benchmarks.
