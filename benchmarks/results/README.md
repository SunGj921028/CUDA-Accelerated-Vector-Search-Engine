# Benchmark result catalog

This directory contains the small, machine-readable records used by the
project documentation. Values are preserved exactly as emitted by the
milestone runners. The runs used normalized deterministic FP32 data, and each
CSV records its workload, warm-up/measurement counts, hardware, CUDA Toolkit,
and compiler metadata.

Results from different milestone runs are not interchangeable. Host-to-device
timing in particular varied between the M2/M4 and M5 process runs, so use
within-file comparisons and retain each file's timing scope.

## M2 — baseline decomposition

- `m2_crossover.csv`: CPU versus `cuda-naive` across database sizes at
  `D=128`.
- `m2_dimension.csv`: CPU versus `cuda-naive` at `D=128,256,768`.
- `m2_stage_timing.csv`: allocation, copies, kernel, CPU Top-K, cleanup, and
  end-to-end timing for the naive CUDA pipeline.

Generated by `scripts/run_m2_benchmarks.py`.

## M3 — block-per-vector

- `m3_primary.csv`: the primary `N=100,000,D=768` run.
- `m3_dimension.csv`: the controlled `D=128,256,768` sweep.
- `m3_small_workload.csv`: the `N=10,000,D=128` overhead check.
- `m3_comparison.csv`: the three groups above in one table. The primary and
  dimension-sweep `D=768` rows are independent runs and are intentionally
  retained separately.

Generated by `scripts/run_m3_benchmarks.py`.

## M4 — warp-per-vector

- `m4_primary.csv`: the headline controlled `N=100,000,D=768` comparison.
- `m4_dimension.csv`: the `D=32..1024` sweep; the final plots use only its
  `D=128,256,768` rows.
- `m4_small_workload.csv`: the `N=10,000,D=128` overhead check.
- `m4_comparison.csv`: the three groups above in one table.

Generated by `scripts/run_m4_benchmarks.py`.

## M5 — GPU-resident database

- `m5_cold_start.csv`: one-shot stateless latency versus resident preparation
  plus first-query latency.
- `m5_comparison.csv`: warm stateless/resident means, medians, and stage means
  over repeated query batches.
- `m5_amortization.csv`: preparation-inclusive totals for 1, 2, 5, 10, 20,
  and 100 query batches.

Generated by `scripts/run_m5_benchmarks.py`. The former `m5_warm.csv` and
`m5_dimension.csv` files were byte-for-byte duplicates of
`m5_comparison.csv`; M5.5 removed those redundant copies without changing any
measurement.

## Figures

Run:

```bash
python3 scripts/plot_final_results.py
```

This reads `m4_dimension.csv` and writes the two final PNG figures under
`docs/images/`. It does not rerun or modify benchmarks.
